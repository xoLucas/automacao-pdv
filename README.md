# 📍 Automação PDV - Manual de Deploy

Este manual tem como objetivo instruir a equipe sobre como realizar o deploy completo da aplicação de rastreamento e automação de PDVs. A arquitetura do projeto divide o sistema em um backend em Python e um frontend estático colaborativo.

---

## 🚀 1. Clonando o Repositório e Configuração Inicial

Primeiramente, defina o diretório local onde o sistema será armazenado e clone o repositório:

```bash
git clone https://github.com/xoLucas/automacao-pdv.git
cd automacao-pdv
```

Após clonar o repositório, prepare o arquivo de variáveis de ambiente:
1. Renomeie o arquivo de exemplo para o nome reconhecido pelo sistema:
   ```bash
   mv api-pdv-tracker.env.example api-pdv-tracker.env
   ```
2. Abra o arquivo `api-pdv-tracker.env` e prepare-se para preencher as variáveis nos próximos passos.
3. **Importante:** Já adicione a sua chave da API do Google Maps (`Maps_API_KEY`) neste arquivo.

---

## 🗄️ 2. Configurando o Banco de Dados (Supabase)

O sistema utiliza o Supabase para armazenamento relacional e sincronização em tempo real.

### 2.1. Criação da Tabela
1. Acesse o painel do seu projeto no [Supabase](https://supabase.com/).
2. Navegue até o **SQL Editor** (no menu lateral).
3. Cole e execute o seguinte script para criar a estrutura dos PDVs:

```sql
CREATE TABLE pdvs (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nome text,
  endereco text,
  cnpj text,
  lat double precision,
  lon double precision,
  status text DEFAULT 'pendente',
  grupo_id text,
  numero_pdv text,
  pad_sub text DEFAULT 'pad'
);
```
*(Aceite a sugestão da plataforma para habilitar o RLS - Row Level Security na tabela recém-criada).*
*(Lembre-se de ativar o Realtime).*

### 2.2. Configuração de Políticas de Segurança (RLS)
Acesse a aba **Table Editor** na barra de navegação à esquerda, vá até **RLS Policies** para a tabela `pdvs` e crie as 3 políticas abaixo executando-as no SQL Editor:

**1. Permitir Inserção (Insert):**
```sql
ALTER POLICY "Enable insert for anon users"
ON "public"."pdvs"
TO anon
WITH CHECK (true);
```

**2. Permitir Leitura (Select):**
```sql
ALTER POLICY "Enable read access for anon users"
ON "public"."pdvs"
TO anon
USING (true);
```

**3. Permitir Atualização (Update):**
```sql
ALTER POLICY "Enable update access for anon users"
ON "public"."pdvs"
TO anon
USING (true)
WITH CHECK (false);
```

### 2.3. Obtendo as Credenciais do Supabase
1. Acesse **Project Settings** (ícone de engrenagem) > **API**.
2. Na seção *API keys*, copie a chave API KEY que começa com sb_publishable e cole na variável `Supabase_Key` no seu arquivo `.env`.
3. Na seção *Data API*, copie a **URL** da API (certifique-se de copiar sem as barras finais, terminando em `.co`) e cole na variável `Supabase_URL` do seu `.env`.

---

## 3. Obtendo as Credenciais do Google Maps
1. Acesse o Google Cloud e busque pela API Key **Geocoding API**.
2. Cole a chave no env.

---

## ⚙️ 4. Deploy do Backend (Render)

O backend (motor de processamento da planilha e geolocalização) será hospedado no Render.

1. Acesse o [Render](https://render.com/) e crie um novo **Web Service**.
2. Conecte o repositório clonado (`automacao-pdv`).
3. Nas configurações do serviço, defina o **Start Command**:
   ```bash
   uvicorn main:app --host 0.0.0.0 --port $PORT
   ```
4. Na seção **Environment Variables** (Variáveis de Ambiente) do painel do Render, cadastre as três chaves do seu arquivo `.env`:
   - `Supabase_URL`
   - `Supabase_Key`
   - `Maps_API_KEY`
5. Finalize a criação e inicie o deploy.
6. Após a publicação bem-sucedida, copie a URL pública gerada pelo Render (ex: `https://sua-aplicacao.onrender.com`).

### 4.1. Conectando Frontend e Backend
Abra o arquivo `index.html` em um editor de texto, localize a declaração da URL base do backend e substitua o valor pela URL copiada no passo anterior:

```javascript
const URL_BACKEND_BASE = "https://sua-aplicacao.onrender.com"; // Substitua pelo link exato do Render
```

---

## 🌐 5. Deploy do Frontend (Netlify)

Com a arquitetura conectada, o último passo é publicar a interface.

1. Acesse o [Netlify](https://www.netlify.com/).
2. Faça o deploy do frontend publicando o seu arquivo `index.html`. Você pode fazer isso conectando o repositório diretamente no painel ou apenas arrastando a pasta do projeto para a área de deploy manual.
3. O Netlify irá gerar um link de acesso imediato.
4. Acesse o link gerado para utilizar o sistema em produção! 🎉
